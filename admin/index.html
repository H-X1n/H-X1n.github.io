连接 GitHub

编辑器通过 GitHub API 直接修改仓库 H-X1n/H-X1n.github.io，需要一个只授权这个仓库的 token：

  1. 打开 GitHub 创建 token 页面（已预填名称、90 天有效期和 Contents 读写权限）
  2. Repository access 选 Only select repositories，勾选 H-X1n.github.io
  3. 确认 Permissions 里 Contents 是 Read and write，点 Generate token
  4. 复制 github_pat_ 开头的 token，粘贴到下面

token 只保存在当前浏览器里，只会发给 api.github.com，不经过任何第三方服务器。
